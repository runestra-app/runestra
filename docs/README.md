# Runestra documentation

Start with the [quick start](../README.md#quick-start), then use these guides to
configure, run and maintain Runestra.

1. [Getting started](getting-started.md): run the sample, restart the system and
   try a small AI workflow.
2. [Write a workflow](workflows.md): define steps, dependencies and outputs.
3. [Project configuration](configuration.md): understand configuration files,
   imports, scheduling and runtime behavior.
4. [Project YAML reference](project-yaml.md): every supported project field,
   version and constraint.
5. [Engine and runner YAML reference](service-yaml.md): deployment settings and
   their defaults and security requirements.
6. [Profiles and actions](profiles-and-actions.md): agent permissions and
   project-defined actions.
7. [Built-in action reference](actions.md): inputs, constraints and outputs for
   every built-in action.
8. [Deployment](deployment.md): install a release or run a Linux server.
9. [Operations](operations.md): accounts, runners, backups and recovery.
10. [Security](../SECURITY.md): trust boundaries and safe operation.
