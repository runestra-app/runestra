# Runestra brand assets

The selected mark follows the user's approved final concept board. Three slanted workflow stages connect into a prominent return loop on the right. The mint, dark and light files use the same editable vector geometry. Final digital exports and practical use rules live in the [visual identity package](../../../Runestra-product/visual-identity/README.md).

| File | Use |
|---|---|
| `runestra-mark-mint.svg` | Mint mark on a dark neutral background |
| `runestra-mark-dark.svg` | Dark mark on a light neutral background |
| `runestra-mark-light.svg` | Light mark on a dark neutral background |
| `runestra-lockup.svg` | Horizontal mark and wordmark |
| `favicon.svg`, `favicon.ico`, `favicon.png` | Browser and app icon exports |
| `social-preview.svg`, `social-preview.png` | Editable social card and its raster export |

The symbol is authored as SVG paths and does not contain a bitmap. The lockup keeps the wordmark as editable SVG text in Inter, with Arial and sans-serif fallbacks. Convert the wordmark to paths before producing a distribution package that must render identically without those fonts.

The return loop distinguishes the mark from three parallel stripes. It remains clear in the selected reference and is now present in the SVG used by the product header and landing page. Use the favicon at 16 px and the standalone mark at 24 px or larger. Static color contrast checks are recorded in the packaged guide. The generated concept board is reference material, the SVG is the production artwork. Trademark and visual similarity review remains open.
